# Community-Created Fukuhedrons 3D Models

This directory contains community-created, open-source 3D models and related resources for the Fukuhedrons collection. The files are intended to give holders a starting point for using the commercial rights granted by HiFo Labs, including product design, content creation, model modification, and rigging.

This is an independent third-party project. It was not created by, endorsed by, or affiliated with HiFo Labs or the official Fukuhedrons collection. Use of the Fukuhedrons characters and underlying intellectual property remains subject to the rights and terms granted by HiFo Labs.

## Downloads

Model packages and comparison previews are published as GitHub Release assets. Each numbered ZIP contains the corresponding Blender file and comparison image. `manifest.json` maps token numbers to their preview and download URLs.
